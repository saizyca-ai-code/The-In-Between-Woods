# 靈感素材區

此資料夾用於保存仍在探索、尚未定案或暫時不適合歸入正式設定的靈感。

## 使用原則

- 新素材可從 `../templates/IDEA_TEMPLATE.md` 複製。
- 不要求每項素材都完整；先保存有價值的核心。
- 對話中提出的新方向應標記為「提案」，不因寫入檔案就自動成為正式設定。
- 當素材發展成正式設定時，依內容類型移至或整理到 `world/`、`characters/`、`locations/` 或 `stories/`，並保留必要的來源與關聯。
- GitHub Projects 可用來追蹤素材狀態；此資料夾則保存需要長期保留的素材內容。

不是每張 Project 卡片都必須對應一個檔案。只有值得長期保存、需要較完整脈絡或會反覆使用的素材，才需要獨立 Markdown 文件。
